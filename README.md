# ZAIA Karaoke – Modern Edition (Beta 0.9.5)

โปรแกรมคาราโอเกะสำหรับ Windows 10 64-bit รุ่นทดลองแรกที่มีหน้าจอ: เลือกคลังเพลง ค้นหา จัดคิว เล่นเพลง EMK พร้อมเนื้อเพลงไล่สี

## วิธีสร้างตัวติดตั้ง (Setup)

1. แตกไฟล์ ZIP ไว้ที่ใดก็ได้ที่ **ไม่ใช่** ในโฟลเดอร์คลังเพลง
2. ดับเบิลคลิก `build_setup.bat` (ต้องต่ออินเทอร์เน็ต) สคริปต์จะ
   - บิลด์โปรแกรม (หา .NET SDK 8 ให้ ถ้าไม่มีจะถามก่อนติดตั้ง)
   - หา Inno Setup 6 ถ้าไม่มีจะถามก่อนติดตั้งผ่าน winget
   - สร้าง `release\ZaiaKaraoke-Setup-0.9.5.exe`
3. ดับเบิลคลิกไฟล์ Setup เพื่อติดตั้ง ไม่ต้องใช้สิทธิ์ผู้ดูแล มีทางลัดใน Start Menu และเดสก์ท็อป ถอนการติดตั้งได้จาก Settings ของ Windows
4. ไฟล์ Setup นี้ส่งให้เครื่องอื่นติดตั้งได้ (Windows 10/11 64-bit)

ถ้าไม่ต้องการตัวติดตั้ง ใช้ `build_all.bat` แล้วเปิดด้วย `run.bat` ได้เหมือนเดิม
ถ้าขึ้น BUILD FAILED หรือ SETUP BUILD FAILED ให้คัดลอกบรรทัดที่มีคำว่า error ส่งกลับมา

การถอนการติดตั้งไม่ลบการตั้งค่าใน `%LOCALAPPDATA%\ZAIA Karaoke` และไม่แตะคลังเพลง

## วิธีใช้

- เปิดครั้งแรกกดปุ่ม "เลือกโฟลเดอร์เพลง" กลางจอ โปรแกรมสแกนแบบอ่านอย่างเดียวและจำโฟลเดอร์ไว้
- แถบควบคุมและช่องค้นหาอยู่ด้านบน ซ่อนเองหลังไม่ใช้งาน 4 วินาทีขณะเล่นเพลง ขยับเมาส์หรือกดปุ่มใดก็กลับมา
- พิมพ์ได้เลยโดยไม่ต้องคลิก รายการเพลงเปิดลงมาจากด้านบนและเนื้อเพลงย่อลงชั่วคราว จึงไม่บังเนื้อเพลงที่กำลังร้อง ลูกศรขึ้นลงเลือกเพลง Enter เพิ่มเข้าคิว Esc ปิด
- ในรายการค้นหามีแท็บ "ทุกเพลง" "เพลงโปรด" "เล่นล่าสุด" และปุ่มเพิ่ม/เอาออกจากเพลงโปรด (F1)
- "สุ่มเพลง" เพิ่มเพลงสุ่มหนึ่งเพลงเข้าคิว
- "วอลเปเปอร์" เปลี่ยนภาพพื้นหลัง (jpg, png, bmp)
- "ตั้งค่า" ปรับได้: ขนาดเนื้อเพลง สีที่ร้องแล้ว/ยังไม่ร้อง เลื่อนจังหวะเนื้อเพลง จุดนับถอยหลัง ความมืดของภาพพื้นหลัง ปิดเสียงทำนองนำ เครื่องเสียง ระดับเสียง และอีควอไลเซอร์ 5 ย่านพร้อมค่าสำเร็จรูป
- ทุกค่าที่ตั้งถูกจำไว้สำหรับการเปิดครั้งต่อไป

### เครื่องเสียงและอีควอไลเซอร์

โปรแกรมแนบ SoundFont `FluidR3_GM.sf2` (โดย Frank Wen สัญญาอนุญาต MIT ดู `soundfonts/FluidR3_GM-LICENSE.txt`) และใช้เป็นเครื่องเสียงเริ่มต้น
ระดับเสียงและอีควอไลเซอร์จึงใช้ได้ทันที เปลี่ยนเป็นไฟล์ .sf2 อื่นหรือกลับไปใช้เสียงของ Windows ได้ใน "ตั้งค่า"
FluidR3_GM เป็นชุดเสียงเครื่องดนตรีสากลมาตรฐาน (General MIDI) ไม่มีเสียงเครื่องดนตรีไทยโดยเฉพาะ

| ปุ่ม | การทำงาน |
| --- | --- |
| พิมพ์ตัวอักษรหรือตัวเลข | เปิดค้นหา |
| Enter | เพิ่มเพลงที่เลือกเข้าคิว |
| Space หรือ F5 | เล่น / หยุดชั่วคราว |
| F6 | หยุดและปิดเพลง |
| F12 | เพลงถัดไป |
| F7 / F8 | คีย์ลง / ขึ้นครึ่งเสียง |
| F9 / F10 | ความเร็วลง / ขึ้น 5% |
| Tab | เปิดปิดคิวเพลง (Delete ลบเพลงที่เลือก) |
| F1 | เพิ่ม/เอาออกจากเพลงโปรด (เพลงที่เลือกในรายการค้นหา) |
| F2 / F3 | เลือกคลังเพลง / สแกนใหม่ |
| F4 | เปิดจอที่ 2 (ลากไปอีกจอแล้วกด F11) |
| F11 | เต็มจอ |

ปุ่มลัดชุดนี้กำหนดขึ้นเอง ยังไม่ได้เทียบกับ eXtreme Karaoke
คีย์และความเร็วกลับเป็นค่าเดิมเมื่อขึ้นเพลงใหม่

ข้อมูลของโปรแกรมเก็บที่ `%LOCALAPPDATA%\ZAIA Karaoke` ไม่มีการเขียน ย้าย ลบ หรือเปลี่ยนชื่อไฟล์ในคลังเพลง

## โครงสร้าง

- `src/Zaia.Core` ตรรกะทั้งหมด (ไม่ขึ้นกับหน้าจอ มีชุดทดสอบ)
  - `Safety/WriteGuard.cs` กันการเขียนลงคลังเพลง
  - `Formats/Emk`, `Formats/Midi`, `Formats/FormatSniffer.cs` ตัวอ่านและตัวจำแนกไฟล์
  - `Library/LibraryScanner.cs` สแกน สแกนเพิ่ม ตรวจไฟล์ซ้ำ
  - `Playback/MidiSequencer.cs`, `Playback/MidiOutput.cs` ตัวเล่น MIDI
  - `Lyrics/LyricTimeline.cs` เวลาไล่สีเนื้อเพลง
  - `App/KaraokeController.cs` คลังเพลง ค้นหา คิว การเล่น
- `src/Zaia.App` หน้าจอ WPF (หน้าจอหลัก เวทีเนื้อเพลง และจอที่ 2)
- `tools/Zaia.Cli` เครื่องมือสำรวจคลังเพลงทางบรรทัดคำสั่ง (`survey.bat "D:\คลังเพลง"`)
- `tests/Zaia.Tests` ชุดทดสอบ: `dotnet run --project tests/Zaia.Tests -c Release -- <โฟลเดอร์ที่มีไฟล์ .emk>`

## ข้อจำกัดของรุ่นนี้

- ผู้พัฒนาทดสอบได้เฉพาะ `Zaia.Core` บน Linux หน้าจอ เครื่องเสียง SoundFont และสคริปต์ติดตั้งของรุ่น 0.9.5 ยังไม่เคยถูกบิลด์หรือรันบน Windows โดยผู้พัฒนา (ผู้ใช้ยืนยันว่ารุ่น 0.9.4 ใช้งานได้)
- เล่นได้เฉพาะ EMK ชนิดอื่น (MP3, MIDI เดี่ยว, MP4, NCN, DAT) ถูกนับตอนสแกนแต่ยังเล่นไม่ได้
- ช่องทำนองนำอ่านจากค่า VOCAL_CHANNEL ในไฟล์โดยสมมติว่านับจาก 1 ยังไม่ได้เทียบกับ eXtreme ถ้าปิดแล้วเสียงที่หายไม่ใช่ทำนองนำ แจ้งกลับได้
- จังหวะไล่สีอิงสมมติฐานจากการวิเคราะห์ไฟล์ 21 ไฟล์ ยังไม่ได้เทียบกับ eXtreme Karaoke
- ยังไม่มี: ฐานข้อมูล SQLite (ใช้ไฟล์ JSON ชั่วคราว), ไมโครโฟนและมิกเซอร์, บันทึกเพลย์ลิสต์, ระบบอัปเดต
